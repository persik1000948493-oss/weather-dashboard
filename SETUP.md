# 🔧 Подробная инструкция установки

## Шаг 1: Получить API ключ

### Способ 1: Бесплатный OpenWeatherMap API

1. Посетите https://openweathermap.org/api
2. Нажмите "Sign Up" в правом верхнем углу
3. Заполните форму регистрации
4. Подтвердите email
5. Перейдите в раздел "API keys"
6. Скопируйте "Default" API key

**Бесплатный план включает:**
- ✅ Текущая погода
- ✅ Прогноз на 5 дней
- ✅ Геолокация
- ❌ 1000 запросов/день (для разработки достаточно)

## Шаг 2: Настройка приложения

### Вариант 1: Прямое редактирование файла

1. Откройте `script.js` в текстовом редакторе
2. Найдите строку 1:
   ```javascript
   const API_KEY = 'YOUR_OPENWEATHERMAP_API_KEY';
   ```
3. Замените на:
   ```javascript
   const API_KEY = 'ваш_api_ключ_здесь';
   ```
4. Сохраните файл

### Вариант 2: Использование переменной окружения (для продакшена)

1. Создайте файл `.env`:
   ```bash
   API_KEY=ваш_api_ключ_здесь
   ```

2. Обновите `script.js` (требует Node.js и npm):
   ```javascript
   const API_KEY = process.env.API_KEY;
   ```

## Шаг 3: Запуск приложения

### Способ 1: Прямое открытие файла

1. Найдите файл `index.html`
2. Дважды кликните на него
3. Браузер откроет приложение

### Способ 2: Локальн��й сервер (рекомендуется)

#### Если установлен Python:
```bash
# Python 3
python -m http.server 8000

# или Python 2
python -m SimpleHTTPServer 8000
```

#### Если установлен Node.js:
```bash
# Установите http-server глобально
npm install -g http-server

# Запустите сервер
http-server
```

#### Если установлен PHP:
```bash
php -S localhost:8000
```

3. Откройте в браузере: `http://localhost:8000`

### Способ 3: GitHub Pages

1. Форкните этот репозиторий
2. Перейдите в Settings → Pages
3. Выберите branch: main
4. Дождитесь деплоя
5. Доступно по адресу: `https://ваш-username.github.io/weather-dashboard/`

## Шаг 4: Проверка работы

1. Откройте приложение в браузере
2. Вы должны увидеть экран поиска
3. Введите название города (например, "Москва")
4. Нажмите "Поиск"
5. Должны загрузиться данные о погоде

## Устранение проблем

### Проблема: "Город не найден"
- ✅ Проверьте правильность написания
- ✅ Попробуйте английское название
- ✅ Добавьте страну: "Москва, Россия"

### Проблема: Нет данных о погоде
- ✅ Проверьте API ключ в `script.js`
- ✅ Перезагрузите страницу (Ctrl+F5)
- ✅ Откройте DevTools (F12) и проверьте Console на ошибки
- ✅ Проверьте интернет соединение

### Проблема: CORS ошибка
- ✅ Это нормально в разработке
- ✅ Используйте локальный сервер вместо прямого открытия файла

### Проблема: Геолокация не работает
- ✅ Дайте разрешение браузеру на доступ к местоположению
- ✅ Используйте HTTPS (на localhost это не требуется)
- ✅ Отключите VPN

## 💡 Советы

1. **Сохраняйте API ключ в безопасности** - никогда не публикуйте в публичных репозиториях
2. **Мониторьте использование API** - в бесплатном плане есть лимит
3. **Оптимизируйте запросы** - приложение обновляется каждые 30 минут
4. **Тестируйте на разных устройствах** - приложение адаптивно
