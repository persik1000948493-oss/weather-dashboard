# 🌤️ Погодный Дашборд

Современный и красивый дашборд для отслеживания погоды в реальном времени. Получайте актуальные данные о погоде, прогнозы на 5 дней и почасовые обновления.

## ✨ Возможности

- 🌍 **Поиск по городам** - Получайте погоду для любого города в мире
- 📍 **Геолокация** - Автоматическое определение вашего местоположения
- 🌡️ **Текущая погода** - Температура, влажность, ветер, давление, видимость
- 📅 **Прогноз на 5 дней** - Полный прогноз погоды
- ⏰ **Почасовой прогноз** - Детальный прогноз на 12 часов
- 💾 **Сохранение истории** - Запоминает последний найденный город
- 📱 **Адаптивный дизайн** - Отлично работает на всех устройствах
- 🎨 **Красивый интерфейс** - Современный градиентный дизайн

## 🚀 Быстрый старт

### Предварительные требования

- API ключ от [OpenWeatherMap](https://openweathermap.org/api)
- Современный веб-браузер

### Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/persik1000948493-oss/weather-dashboard.git
   cd weather-dashboard
   ```

2. **Получите API ключ:**
   - Перейдите на [OpenWeatherMap](https://openweathermap.org/api)
   - Зарегистрируйтесь (бесплатно)
   - Создайте новый API ключ
   - Скопируйте ключ

3. **Добавьте API ключ:**
   - Откройте `script.js`
   - Найдите строку: `const API_KEY = 'YOUR_OPENWEATHERMAP_API_KEY';`
   - Замените `YOUR_OPENWEATHERMAP_API_KEY` на ваш ключ

4. **Откройте в браузере:**
   - Дважды кликните на `index.html` или
   - Используйте локальный сервер:
     ```bash
     python -m http.server 8000
     # или
     npx http-server
     ```
   - Откройте `http://localhost:8000` в браузере

## 📡 API Endpoints

### Получение координат по названию города
```
GET /geo/1.0/direct?q={city}&limit=1&appid={API_KEY}
```

### Текущая погода
```
GET /data/2.5/weather?lat={lat}&lon={lon}&lang=ru&units=metric&appid={API_KEY}
```

### Прогноз на 5 дней
```
GET /data/2.5/forecast?lat={lat}&lon={lon}&lang=ru&units=metric&appid={API_KEY}
```
